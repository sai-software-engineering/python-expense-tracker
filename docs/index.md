# Python Expense Tracker

Welcome to the technical documentation of Python Expense Tracker.

Python Expense Tracker is a personal finance management application
developed using Python and FastAPI.

## Project Overview

The application helps users manage income, expenses, categories,
and financial reports.

## Technology Stack

| Component | Technology |
|---|---|
| Backend | Python, FastAPI |
| Frontend | HTML, CSS, JavaScript |
| Database | SQLite |
| ORM | SQLAlchemy |
| Validation | Pydantic |
| Diagrams | PlantUML, Mermaid |
| Documentation | Markdown, MkDocs |
| Hosting | GitLab Pages |
